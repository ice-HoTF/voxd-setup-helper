1: Download:
https://github.com/jakovius/voxd/releases/tag/v1.7.0

2: Install Dependencies:
sudo pacman -S --needed base-devel git cmake python-pip python-pyqt6 python-pyyaml python-requests python-setuptools ydotool xclip wl-clipboard alsa-plugins pipewire-pulse pavucontrol
sudo pacman -S pyenv

3: Export variables through bashrc
nano.bashrc
add:
export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"
eval "$(pyenv init -)"
export YDOTOOL_SOCKET="$HOME/.ydotool_socket"

4: Save
source ~/.bashrc

5: Install packages:
sudo pacman -S --needed base-devel openssl zlib xz tk sqlite ncurses bzip2 libffi

6: Install pyenv
pyenv install 3.9.18

7: Install voxd:

cd /home/$USER/
git clone https://github.com/jakovius/voxd.git
cd voxd

8: Create python venv:
python -m venv .venv

9: Save and activate venv:
source .venv/bin/activate

10: Install pip:

nano pyproject.toml
Find this line:
<version = "mr.batman">
Change it to a proper version number:
<version = "0.1.0">

11: Install pip:
pip install -e .


12: After Reboot, Run Initial Setup

cd /home/$USER/voxd
source .venv/bin/activate
voxd --setup


Done!

EXTRAS:

Toggle record/stop Keybinding:

In your desktop environment's keyboard settings, add a custom shortcut with:
bash -c 'voxd --trigger-record'


Start voxd:

Create Script:

1. Create a script file:

nano ~/start-voxd.sh


2. Add this content:

#!/bin/bash
cd /home/$USER/home/voxd/
source .venv/bin/activate
voxd --tray

3. Make it executable:

chmod +x ~/start-voxd.sh

Auto launch script on boot, make it a desktop shortcut or whatever.

Launch voxd through alias:

alias voxd='/home/$USER/start-voxd.sh'
